# Angular starter

A minimal Angular app in TypeScript with the router and Vitest, no server-side rendering.

- `src/app/app.ts`: the root component
- `src/app/app.html`: its template
- `src/app/app.routes.ts`: the routes
- `src/styles.css`: global styles
- `angular.json`: Angular workspace configuration

## Run

```sh
npm install
npm start
```

Then open http://localhost:4200.
